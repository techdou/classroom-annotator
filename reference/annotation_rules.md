# 三级标注判定规则（金标准校准版）

本文件是 Stage 4 推理的**判定规则权威来源**，经澳大利亚课金标准（109 操作/43 行为/7 活动）三轮校准（v1→v2→v3）。stage4_prep.py 任务包内嵌的 OP_RULES 是本文操作级的精简版，两处内容以本文为准。

核心教训：类型判定的常见错误不是"看不懂"，而是**判定口径比金标准松**——金标准把大量直觉上像提问/展示/使用的段都标成讲述。拿不准时向讲述收敛。

## 操作级规则（R1-R4）

- **R1 巡视合并**：巡视（PA）期间教师的简短提示语不独立成段，并入巡视段。
- **R2 切换即讲述**：翻页/切换课件/按计时器等设备操作时教师在讲话 → 讲述（TL）+口头语言，不标使用（OP）。使用仅用于教师操作设备且不说话的纯操作段（通常仅数秒）。
- **R3 展示收敛**："看一下/看课本X页/翻到X页"等短暂观察指示嵌入讲授 → 讲述，不标展示（DP）。展示仅用于学生持续观察材料成为主要活动的段（如指示看图后学生看图作答）。
- **R4 提问收敛**：教师连续追问、反问、自问自答、快速核对（"同意不""是不是"）→ 讲述。提问（QN）仅用于明确点名/邀请学生作答且学生实际作答的独立段（"来，你说一下""谁愿意上台"）。

## 操作类型速查（11 类，含判定倾向）

| 类型 | 判定要点 |
|---|---|
| 书写WR | 新增文字/符号/图形到黑板/PPT批注区/纸质材料（擦除已有内容是擦改） |
| 擦改EC | 对已有内容擦除/删除/订正 |
| 展示DP | 学生持续观察材料为主（R3 收敛，少用） |
| 指向PT | 手/教鞭/激光笔明确指向具体位置（纯视觉特征，ASR 无信号，依赖视觉事件） |
| 播放PL | 启停视频/音频/自动动画 |
| 使用OP | 教师操作设备且不说话的纯操作段（R2 收敛，少用） |
| 演示DE | 操作实物/教具/实验器材呈现过程 |
| 巡视PA | 走入学生座位区走动查看（R1：期间简语并入） |
| 观察OB | 教师原地看/听学生活动（学生汇报/讨论时教师倾听） |
| 讲述TL | 口头讲授/归纳/评价/追问/反问/自问自答（**默认兜底类型**） |
| 提问QN | 明确点名邀请+学生实际作答的独立段（R4 收敛，少用） |

## 金标准用量画像（47.8 分钟课，109 操作）

讲述 60+ / 巡视 20 / 指向 8 / 观察 4 / 书写 4 / 使用 4 / 提问 3 / 展示 2 / 播放 1。

**自检**：标注结果的提问或展示若远超此量级（如提问 >8），说明 R3/R4 执行不到位，回去收紧再交付。

## 行为级规则（RB1-RB2）

- **RB1 反馈边界**：答案核对/讲评阶段的归纳讲解、展示参考答案组织学生评判给分，归入**提供反馈（PF）**，不另立提供学习指导（PG）。学生独立练习+教师巡视收集表现证据 → **检测学习结果/评价行为（EP）**，不是诱发（IB）。
- **RB2 诱发 vs 指导**：以学生产出为主的问答回合（学生汇报+教师肯定+继续邀请补充）→ 诱发学习行为（IB）；以教师组织方法/示范为主 → 提供学习指导（PG）；围绕学生成果的连续追问引出全班分析 → 诱发（IB）。

行为易混对照（九段教学行为）：呈现刺激材料（SP）用于新材料首次登场（新图表组、播放视频）；材料出现后围绕它的讲解问答归 PG/IB，不要一路 SP 到底。

## 粒度校准

操作级中位 10-15s，短可 2-3s，静默做题/讨论段可长达 1 分钟+；讲述长段（>40s）按内容主题切换拆分。金标准会把讲授中的模式切换（讲→指→写）切得很细（2-10s 段），视觉证据充分时才跟进细切，证据不足不硬切。
